# Croc Jump

**Author:** 2B Wong Yin Lun

An endless vertical platformer starring a square crocodile.

**Play:** https://s20250144-bit.github.io/Eason/

## Controls

- **Desktop:** `Space` / `↑` / `W` to jump, `R` for a rocket boost, `←` `→` / `A` `D` to move, `X` / `J` or click to slash, `P` to pause, `M` to mute.
- **Mobile:** use the on-screen arrows, the gold **↑** jump button, the rocket button, the sword button, and the pause button.

Stomp swamp mobs from above or slash them with the blade. The rocket gives a high jump on a 4.2-second cooldown. You have three hearts.

## Deployment

Pushes and merges to `main` automatically deploy the site with GitHub Actions:

- Workflow: `.github/workflows/deploy.yml`
- Pages source: **GitHub Actions**
- Site URL: https://s20250144-bit.github.io/Eason/

The workflow can also be triggered manually from the **Actions** tab.
